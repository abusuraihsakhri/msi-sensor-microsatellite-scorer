Microsatellite Instability — Bethesda Panel Explorer

Five-marker PCR classification and mismatch repair (MMR) immunohistochemistry pattern review

Research / educational use only. This tool classifies manually supplied marker observations, not raw sequencing reads. It is not an implementation of the MSIsensor sequencing algorithm, a validated diagnostic device, a Lynch syndrome diagnosis, or a treatment recommendation. Interpret findings with the validated assay and clinical context. Do not enter patient identifiers.

Single-sample assessment

Choose stable or unstable for each of the five Bethesda markers. Two or more unstable loci classify as MSI-H; one as MSI-L; none as MSS.

Batch CSV assessment

Process a CSV locally and download classified records. Required headers: BAT-25,BAT-26,D2S123,D5S346,D17S250. Values: stable/unstable or true/false. Optionally include all four columns MLH1,MSH2,MSH6,PMS2 with retained/lost, plus BRAF_V600E and MLH1_PROMOTER_METHYLATION.

Maximum 2 MB or 5,000 records; malformed or missing marker data are rejected. Files are processed on this device only and are not sent to a server. Avoid protected health information.

Bethesda-panel classification is distinct from next-generation sequencing MSIsensor scoring. Source and Python CLI: GitHub repository. MIT license.
